# 知识库「零售数据口径」

演示应用「零售数据 ETL」的「查业务口径」节点检索这个知识库。`make demo` 会建库并上传本目录下除本文件外的全部文档。

模拟业务部门（经营分析部）维护的指标口径：

| 文档 | 内容 |
| --- | --- |
| 01-有效订单定义.md | 哪些订单算有效：状态 paid、shipped、completed（去空格转小写），排除测试账号；数量小于等于 0 的明细不算 |
| 02-销售额与客单价.md | 销售额 = 数量 × 单价 × (1 − 折扣率)，空折扣按 0，不含运费；订单数、客单价 |
| 03-城市与会员等级.md | 城市去空格、去「市」、空值归「未知」；会员等级转小写、空值归 normal；渠道取值 |
| 04-时间口径.md | 以下单时间为准、按自然月 yyyy-MM、不做时区转换 |
| 05-客户数与复购.md | 下单客户数按 customer_id 去重；复购客户和复购率；新客户 |
| 06-毛利.md | 毛利 = 销售额 − 数量 × 成本价；毛利率；品类为空归「未分类」 |

口径里的取值和 MySQL 示例库 `retail`（`connectors/mysql/seed/003-retail.sql`）里故意埋的脏数据一一对应，改文档时要对照种子数据，`backend/tests/test_demo.py` 会检查。
