# 城市与会员等级

- 适用范围：按城市、会员等级、渠道拆分的所有零售指标
- 版本：v1.4（2026-07-01 更新）
- 维护部门：经营分析部

## 城市

订单表没有城市，统计用的城市是**下单客户的注册城市** `customers.city`，按客户当前档案统计，不追溯历史变更。

源数据里城市的写法不统一，统计前按下面的顺序归一：

1. 去掉首尾空格：「 上海 」→「上海」。
2. 去掉末尾的「市」字：「上海市」→「上海」。
3. 为空（NULL 或空字符串）的归为「未知」。

```sql
coalesce(nullif(regexp_replace(trim(c.city), '市$', ''), ''), '未知')
```

归一后只有 8 个城市和「未知」：上海、北京、杭州、南京、苏州、深圳、广州、成都。报表里「未知」单独列出，不要丢掉，否则各城市加总对不上全国数。

## 会员等级

会员等级取 `customers.member_level`，统一成小写英文代码：

| 代码 | 中文名 |
| --- | --- |
| `normal` | 普通会员 |
| `silver` | 银卡会员 |
| `gold` | 金卡会员 |

源数据里有 `Gold`、`SILVER` 这类大小写不一的写法，先去空格再转小写。等级为空的客户按普通会员 `normal` 统计。

```sql
coalesce(nullif(lower(trim(c.member_level)), ''), 'normal')
```

## 渠道

渠道取 `orders.channel`：`online`（线上商城）、`store`（门店）、`mini_program`（小程序）。需求里说“线上渠道”时指 `online` 和 `mini_program` 两个；只说“线上商城”时才只指 `online`。

## 常见错误

- 直接按 `city` 原值分组：同一个城市会拆成「上海」「上海市」「 上海 」三行。
- 把城市为空的客户过滤掉：这部分订单的销售额就从报表里消失了。
- 会员等级区分大小写分组：`gold` 和 `Gold` 被当成两个等级。
