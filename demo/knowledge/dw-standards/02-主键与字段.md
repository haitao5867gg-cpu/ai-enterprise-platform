# 主键与字段

- 适用范围：dwd、dws 层所有表
- 版本：v1.6（2026-08-12 更新）
- 维护部门：数据平台组
- 要点：每张表都声明主键（明细表用来源主键，汇总表用全部维度列）；金额 `decimal(18,2)`、比率 `decimal(10,4)`、计数 `bigint`，金额和比率要显式转换类型，分母为 0 时给空值。

## 主键

- 每张表都必须声明主键（方案里的 `primary_key`）。
- 明细表保留来源主键：订单明细表的主键是 `order_id`、`line_no`。
- 汇总表的主键是全部维度列的组合：按城市、会员等级、月汇总的表，主键是 `stat_month`、`city`、`member_level`。
- 主键列不能为空；维度列的空值要先按业务口径替换成默认值（如城市「未知」、会员等级 `normal`、品类「未分类」），再作为主键。

## 字段类型

| 含义 | 类型 | 例子 |
| --- | --- | --- |
| 金额（含客单价等金额的商） | `decimal(18,2)` | `sales_amount`、`gross_profit`、`avg_order_value` |
| 比率 | `decimal(10,4)` | `repurchase_rate`、`gross_margin` |
| 计数 | `bigint` | `order_count`、`customer_count` |
| 数量 | `int` | `quantity` |
| ID | `bigint` | `order_id`、`customer_id` |
| 日期 | `date` | `stat_date` |
| 时间 | `timestamp` | `ordered_at` |
| 月份 | `string`，`yyyy-MM` | `stat_month` |
| 编码和名称 | `string` | `city`、`member_level`、`channel` |

- 金额、比率必须显式转换类型，例如 `CAST(x AS DECIMAL(18,2))`，PySpark 里写 `.cast("decimal(18,2)")`，不要留成 double。
- 除法结果（客单价、比率）分母为 0 时给空值，不要给 0。

## 列说明

每一列都写中文说明（方案里的 `description`）：含义、单位、口径出处，例如“销售额，元，不含运费，口径见《销售额与客单价》”。
