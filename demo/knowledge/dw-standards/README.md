# 知识库「数仓开发规范」

演示应用「零售数据 ETL」的「查开发规范」节点检索这个知识库。`make demo` 会建库并上传本目录下除本文件外的全部文档。

模拟数据平台团队维护的开发规范：

| 文档 | 内容 |
| --- | --- |
| 01-分层与命名.md | ods / dwd / dws 分层，表名「层_业务域_主题_粒度」，列名小写蛇形 |
| 02-主键与字段.md | 每张表都有主键，汇总表主键是维度组合；金额 decimal(18,2) 等字段类型 |
| 03-数据质量规则.md | 质量规则逐行判断、drop / warn / fail 的用法、必须有的规则、唯一性用主键表达 |
| 04-加载策略.md | 明细表按下单时间增量，汇总表全量重算，可重复运行 |
| 05-PySpark编码规范.md | 函数体写法、source() 读源表、禁止的写法、推荐写法和例子 |

PySpark 规范必须和平台的代码静态检查（`backend/src/aep/etl/codegen.py`）一致，不能建议检查会拒绝的写法，`backend/tests/test_demo.py` 会检查文档里的代码例子。
